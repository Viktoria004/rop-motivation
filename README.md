## Зарплатный калькулятор РОПа

Маршрут `/dashboard/`, исходники `src/dashboard/`. Собирается той же командой `npm run build` и использует общий `src/calculation.ts`, без копии бизнес-правил. Дизайн по формату кабинета МПП: выплата, план, раскрываемые начисления и отдельный раздел настроек.

Начальные значения — демонстрационный пример, не реальные показатели команды. CRM не подключена. Планы продаж сохраняются по месяцам в localStorage браузера, демонстрационные показатели остаются в памяти вкладки и сбрасываются при обновлении. Оклад фиксирован за полный месяц.

Выплата за месяц = текущие премии после коэффициента + оклад − демотивация + подтверждённая сумма за декларации прошлых продаж (уже после исходного коэффициента). Декларации текущих продаж показаны отдельно как предварительная будущая выплата. Сценарии удалены. На главном экране нет полей ввода: план задаётся в «Настройки → План продаж на месяц» и применяется кнопкой «Сохранить план». Цели качества выбираются по месяцу: 77/80/85/90%, после января 2027 — 90%.

Проверки: `node --test tests/*.test.mjs`, `npm run build`.
